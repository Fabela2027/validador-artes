# Validador de Artes

Revisa que los artes de una campaña vengan a la medida, resolución y formato que pide cada soporte o media owner.

- Abre la página, sube el plan de campaña (Excel) y la carpeta o el ZIP de artes.
- Los archivos se revisan en tu navegador; no se suben a ningún servidor.
- El catálogo de soportes del equipo está en `soportes.json`. Para actualizarlo, edítalo en la app, usa "Descargar catálogo" y reemplaza este archivo en el repositorio.
